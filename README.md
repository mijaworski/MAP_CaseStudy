# Zalando — AI personal styling (concept prototype)

Live demo: https://<your-username>.github.io/<repo-name>/

A self-contained, single-file prototype: `index.html` holds both pages, the 3D avatar and all product images, so nothing else needs to be served.

## Publish with GitHub Pages
1. Push `index.html`, `.nojekyll` and this README to the root of the repository.
2. Settings → Pages → Build and deployment → **Deploy from a branch** → `main` / `/ (root)` → Save.
3. The demo is live at `https://<your-username>.github.io/<repo-name>/` after about a minute.

`.nojekyll` tells GitHub Pages to serve the file as-is instead of running it through Jekyll.
